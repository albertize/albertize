# Profile artwork

- `profile.svg`: the complete profile graphic, with technology icons embedded inline.
- `linkedin.svg` and `reddit.svg`: local contact buttons.

Technology icons come from [Devicon](https://github.com/devicons/devicon).
The original MIT license is preserved in [LICENSE.devicon](./LICENSE.devicon).
Their vector paths are embedded in `profile.svg`, with adjusted sizes and namespaced IDs.
Brand names and logos belong to their respective owners.

All graphics render without external image requests.
