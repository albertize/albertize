# Technology icons

Source: [Devicon](https://github.com/devicons/devicon), downloaded from its `master` branch.

The SVG files in this directory are local copies. The original license is included
in [LICENSE](./LICENSE). Brand names and logos belong to their respective owners.

`../stack.svg` embeds these vectors directly, with namespaced IDs and sizing for
the profile cards. It makes no external image requests.

SQL and REST use custom text symbols rather than product logos.
